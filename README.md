# Biker-Zone

A modern web project for motorcycle enthusiasts, featuring product showcases, interactive elements, and a responsive design.

## Live Demo

[GitHub Pages Demo](https://showrav-sarkar555.github.io/Biker-Zone/)

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## Features
- Product slider
- Iconography and images
- Responsive layout
- Modern UI components

## How to Run Locally
1. Clone the repository:
   ```sh
   git clone https://github.com/showrav-sarkar555/Biker-Zone.git
   ```
2. Open `index.html` in your browser.

## Folder Structure
- `images/` - Contains icons and slider images
- `index.html` - Main HTML file
- `tailwind.config.js` - Tailwind CSS configuration
